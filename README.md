# Bike Sales Dashboard Using Microsoft Excel

##   Project Overview

How can we understand customer buying behaviour through data?

This project gave me an opportunity to explore that question using Microsoft Excel. I worked on a bike sales dataset to understand how factors such as age, income, marital status, and commute distance relate to bike purchasing decisions.

I completed this project as part of my Data Analytics training at the **American India Foundation (AIF)**.

##   Project Objectives

- Clean and organize the raw sales dataset.
- Explore customer demographics and purchasing behaviour.
- Analyze income and bike purchase patterns.
- Understand purchasing trends across different age groups.
- Build an interactive Excel dashboard.

##  Tools & Skills Used

- Microsoft Excel
- Data Cleaning and Preparation
- IF and Nested IF Formulas
- PivotTables
- PivotCharts
- Interactive Slicers
- Data Visualization
- Dashboard Creation

##  Data Cleaning

- Converted M/F into Male/Female.
- Converted M/S into Married/Single.
- Created Age Brackets using Nested IF formulas:
  - Young: Below 31
  - Middle: 31–64
  - Old: 65+

##  Key Analysis

Created PivotTables and charts to explore:

1. Average Income by Gender and Bike Purchase Status – Column Chart.
2. Commute Distance by Bike Purchase Status – Line Chart.
3. Bike Purchases by Age Bracket – Stacked Bar Chart.

##  Interactive Dashboard

Combined the charts into a single Excel dashboard.

The dashboard includes interactive slicers for:

- Marital Status
- Region
- Education

These slicers are connected to the dashboard charts, allowing users to explore different customer segments.
